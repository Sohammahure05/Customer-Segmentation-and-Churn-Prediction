# Customer Segmentation and Churn Prediction

## Overview

This project combines Customer Segmentation and Customer Churn Prediction using Machine Learning.

### Customer Segmentation

* Algorithm: K-Means Clustering
* Features:

  * Tenure Months
  * Monthly Charges
  * Total Charges

### Churn Prediction

* Algorithm: Random Forest Classifier
* Accuracy Achieved: 93%

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Seaborn
* Google Colab

## Results

* Created 4 customer segments using K-Means clustering.
* Predicted customer churn with 93% accuracy.
* Generated confusion matrix and feature importance analysis.
